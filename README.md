# Revisjonsmotor — nettsted

Statisk nettsted for revisjonsmotor.no.

- `index.html` — forside
- `slik-fungerer-det.html` — detaljert forklaring (oppdateres løpende)
- `styles.css` — delt designsystem (brandfont Inter, glass-uttrykk, subtil hover, mus-lys)

Ingen byggesteg — ren HTML/CSS. Åpne `index.html` i nettleseren for å se den lokalt.

## Gjenstår før lansering
- Koble demo-skjemaet til et ekte endepunkt (egen API / Formspree e.l.).
- Sett riktig app-URL på «Gå til Revisjonsmotor» (nå: https://app.revisjonsmotor.no/).
- Lag delebilde `og-image.png` (1200×630) og legg i rot.
- Oppdater integrasjonslista når koblinger faktisk er live.
